## 3. External prerequisites (must be met before a pilot go-live)

1. **Off-host backup (T44-P1-11 — open).** A real off-host destination with root-only credentials, encryption at rest
   confirmed, `BACKUP_OFFHOST_REQUIRED=true` with both hook commands, the backup timer active, and a restore **from the
   remote copy** into an isolated database and directory performed and timed (checklist §4 of the acceptance document).
2. **Monitoring and alerting (T44-P1-12 — open).** External HTTPS uptime probe, readiness probe, backup freshness and
   failure alerts, document-storage and disk thresholds, process supervision — each simulated failure confirmed as
   **received by a named operator** (checklist §5).
3. **TLS and reverse proxy** with the shipped security headers, verified on the real URL (`npm run ops:verify-web`).
4. **Production configuration** passing `npm run ops:preflight` on the host (`NODE_ENV=production`, `TRUST_PROXY`,
   `PUBLIC_APP_URL`, `CORS_ORIGIN`, `COOKIE_SECURE=true`, storage and backup paths).
5. **PostgreSQL**: dedicated database, least-privilege role, provider-side disk monitoring.
6. **Named owners** for monitoring, backup alerts, restoration, off-host credentials, backup schedule and production
   approval — all **TBD** today (acceptance document §6).
7. **Two System Administrators** named by the customer; bootstrap password changed; roles reviewed.
8. **Each organization's IANA timezone** set correctly.
9. **Copilot stays disabled** (`COPILOT_ENABLED=false`, the default). Enabling it requires a live-provider adversarial
   smoke test recorded before go-live (docs/hr-copilot.md §14.6); live-provider behaviour is UNVERIFIED.
10. **Customer data-protection paperwork**: privacy notice, legal basis, retention schedule, request owner.

## 4. Known limitations

Single node (in-memory rate limiters, local document storage, no HA); no email delivery (reset links handed over by a
secure channel); MFA, idle session timeout and per-account login throttling open (P2-25, P2-03, P2-04); business
records carry no timezone snapshot (docs/business-dates.md §7); copilot classifier is rule-based
(docs/hr-copilot.md §14.6).

## 5. Not in this release

Timesheets, SSO/SAML/OIDC, MFA, external notification delivery, multi-tenancy, high availability.
